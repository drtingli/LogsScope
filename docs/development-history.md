# 开发历史（Development History）

以下内容为第一版发布前的开发演进记录，已移除版本号，仅作为变更列表。

- **分离窗口修复：** 点击 Detach 后正常显示日志内容，不再只剩一条颜色线；重新附加仍保留原日志页。
- **书签面板默认隐藏：** 启动时不再自动打开书签面板，需要时按 Ctrl+B 或点工具栏的 Bookmarks 按钮打开。
- **窗口主题：** Options → **Window theme** 可选 *Follow Windows*（默认，跟随 Windows 的深色 / 浅色设置，系统切换时自动跟随）、*Light* 或 *Dark*。菜单、工具栏图标、对话框、面板及 Windows 标题栏都会随之切换；Appearance 中留空的日志面板颜色跟随窗口主题，已手动设置的颜色保持不变；默认的浅灰网格线在深色主题下自动变暗。选择保存在 settings.json（`ui_theme`）。
- **活动 LED：** 每个标签的文件名前面有一个小圆形 LED。开着 Follow tail 的标签，有新行到达时 LED 闪一下（亮绿色，带光晕，约 0.25 秒淡出）；
 日志持续写入时会以每秒 8 次左右的频率连续闪烁，而不是一直亮着。没有新行时是深绿色（正在跟随）；Follow tail 关闭时是灰色，不闪。
 文件刚打开、初次读取的那一批行不算新行，不会闪。鼠标悬停显示说明；点击和拖动标签不受 LED 影响。
 View > "Activity LED in the tabs" 可以整体关闭或打开（设置项 `activity_led`）。分离出来的窗口没有标签栏，所以没有 LED。

整个视图现在是一棵“区域”树：每个**区域**有自己的标签栏、显示其中一个标签；区域之间用分隔条并排或上下堆叠，
可以任意嵌套、任意数量（3 列、4 行、2×3 网格、一列里再分两行……）。上限：64 个区域，嵌套 8 层。

- **拖放标签：**
 - 拖一个标签到**另一个区域的标签栏**上，标签就移到那个区域（落在哪个位置就插到哪里，同一个标签栏里也可以这样重新排序）；
 - 拖到区域的**页面部分**时，靠近**四条边**（边缘约 28%）就在那一侧新建一个列或行（出现蓝色半透明提示），
  放在**中间**则加入该区域。区域里只剩一个标签时，拖到它自己的边上不会有变化。
 - 区域被拖空后自动消失，分隔条自动合并（同方向的分隔条会并成一层）。
- **预设布局**（View > Layout）：Tabs（一个区域）、Side by side（每个标签一列）、Stacked（每个标签一行）、Grid。
 手动拖放或增删区域后显示为 "Custom"。预设布局下新开的标签自动得到自己的区域；Custom 下加入当前活动区域。
- **Arrange in columns × rows…：** 任意列数 × 行数（各最多 8，总数最多 64），标签按顺序分配；
 标签多于格子时同一区域里有多个标签，标签少于格子时多出的格子留空等你拖入。有 "3 columns"、"4 rows"、"2 × 2"、"3 × 2" 快捷按钮。
- **区域菜单（标签栏右边的 ⋮）：** 把当前标签移到新区域（右 / 下 / 左 / 上，需要该区域至少两个标签）、移到另一个区域、
 在四个方向添加空区域、关闭本区域（标签并入相邻区域）、把所有区域合并成一个。标签右键菜单里的 Area 子菜单提供同样的功能（无需拖动）。
- **活动区域**有较粗的蓝色边框；点击或把键盘焦点放进某个区域就切换。多个区域时，空区域里有 "Remove this area" 按钮。
- **保存：** 区域布局（嵌套结构、分隔条比例、每个区域里的标签及当前标签）随会话保存，下次启动恢复。
 合并 / 过滤产生的临时标签不保存，只含这类标签的区域不保存。设置里的 `layout` 记录当前预设或 `custom`。

- **Timestamp 拆成 Date 和 Time：** 解析规则（正则 columnizer）里名为 Timestamp / DateTime 的组，现在默认显示为 **Date | Time** 两列，
 例如 `2026-11-13T17:02:11.976` 变成 `2026-11-13` 和 `17:02:11.976`。规则对话框里有开关
 "Show a Timestamp / DateTime column as two columns"（旧规则没有这项设置，按开启处理）。
 不是日期时间的内容（如纯数字的 epoch 秒）整个放在 Time 列。
- **时间差同时用日期和时间：** 时间差、同步、合并读取的是整行里的完整时间戳，所以带日期的日志跨过午夜也是正确的。
 **没有日期、只有时间的日志：** 假定日志在午夜单调推进——时间突然往回跳超过 12 小时，就当作新的一天
 （小的回退，比如线程交错造成的几毫秒，不算）。选中的两行相隔很远时，会在它们之间抽样最多 2 万行来找午夜，
 所以 10:00 到第二天 09:00 这样的选择也能算对。Δt 的结果里会写 "crosses midnight N×"。
 这一条只用于时间差；时间同步和合并对无日期日志仍不处理跨午夜。
- **标签管理对话框：** Tags 按钮菜单第一项 "Manage tags…"，或 Bookmarks 菜单里的 "Manage tags…"。列表显示每个标签在当前文件、
 所有已打开文件里的书签数，以及是否在建议列表里。可以：**新建**（加入建议列表）、**重命名**（所有已打开文件的书签同步改名；
 改成已有名字时询问是否合并）、**删除**（从所有书签和建议列表里去掉，书签本身保留）、清理没人用的建议。改动立即生效。
 关闭的文件不受影响，打开后再改。
- **书签列更宽：** 宽度按书签标记（emoji）的实际宽度计算，不再被截断；Pin 列也略宽。
- **列标题靠左：** 表头文字靠左对齐，长行的 "Message" 不会再被挤到屏幕外。

- **右键菜单：** 主面板、过滤结果、搜索结果面板和置顶区都有右键菜单。右键点击未选中的行会先选中该行。
 默认项（按使用频率排列）：复制行、复制当前字段｜查找 / 只显示包含 / 隐藏包含 / 高亮 "字段文字"｜加 / 去书签、带注释的书签、
 置顶｜在主视图中显示、选中行时间差、选中行 → 新标签页、跳到源行（派生页）｜自定义菜单。
 不适用的项自动隐藏或变灰（例如时间差需要选中两行以上）。
- **自定义：** Options > Context menu…（也可在菜单最后一项或右键菜单里点 "Customize this menu…"）。
 可以上移 / 下移、删除、添加内置项（还有 "复制带行号"、"复制路径和行号" 等默认不显示的项）、添加分隔线，
 以及添加**自定义命令**：菜单文字 + 程序 + 参数。参数里可用占位符 `{line}`（整行）、`{field}`（点击的字段）、
 `{lineno}`、`{file}`、`{selection}`（所有选中行）。参数先拆分、再填入占位符，日志文字里的引号不会改变命令结构；
 不经过 shell；`.bat` / `.cmd` 里的危险字符会被替换成空格。设置保存在 `context_menu`，可一键恢复默认。
- **Shift + 滚轮：** 在三个面板和置顶区里按住 Shift 滚动鼠标滚轮即水平滚动（滚轮向上向左，向下向右）；
 在置顶区里滚动时也是移动面板的水平滚动条。
- **表头 "Message"：** 单列显示（Default columnizer）时，表头文字由 "Log" 改为 "Message"。

- **点击不再自动水平滚动：** Qt 默认会为了让被点击的单元格完全可见而横向滚动。现在主面板、过滤结果和搜索结果面板
 只会纵向滚动到目标行，水平滚动条只由你自己移动（拖动滚动条、滚轮，或方向键左 / 右，每次 4 个步长）。
 跳转到行、查找、双击书签等操作同样不再改变水平位置。
- **独立的书签列：** 在 Line 列前面多了一个很窄的书签列。已加书签的行在这里显示标记（主题里的标记，或该书签自己的 emoji），
 **双击这个单元格就设置 / 取消该行的书签**（主面板、过滤结果、搜索结果面板都可以；Ctrl+F2 照常可用）。
 Line 列现在只显示行号。
- **置顶行（sticky）：** 书签列后面是 Pin 列，每行有一个小复选框。勾选后该行出现在面板顶部的置顶区，
 滚动时不动；置顶区和面板用同样的列宽、颜色和水平滚动。取消勾选（在面板或置顶区里都行）即移除。
 主面板、过滤结果、搜索结果面板各有自己的置顶行；置顶区最多显示 8 行，更多时在区内滚动，每个面板最多 1000 行。
 主面板的置顶行会保存在会话里，文件被重置或变短时自动清理。双击置顶区的行会跳到主面板对应行。
- 书签 / Pin 列默认只有一个字符宽，可以自己拖宽。

- **日期 / 时间拆分：** 自动检测到的时间戳（ISO 8601 及类似格式，包括 `[2026-11-13T17:02:11.976]sys=...` 这种方括号写法）
 现在分成 **Date | Time | Message** 三列（columnizer 名称 "Date | Time | Message"）。前几行（至少 3 行，且占样本 30% 以上）
 有时间戳就会选用它。带日志级别的行用 "Date / Time / Level / Message"，级别只认 INFO、WARN、ERROR 等标准词，
 不会再把消息的第一个词当成 Level。
- **时间计算与拆分的关系：** Date 和 Time 列取自时间戳解析器找到的同一段文字，所以时间差、同步、合并读到的时间与列里显示的一致。
 `core/timefields.py` 里的 `fields_epoch(date, time)` 可以把两个单元格转回秒数；正则规则里命名为 Date / Time / Timestamp 的组
 会被识别为时间列（`column_roles()`）。
- **预定义正则：** `core/timefields.py` 里有日期、时间、ISO 8601 日期+时间、方括号时间戳、日/月/年、日志级别等片段。
 解析规则对话框里的 "Insert a predefined pattern at the cursor" 把它们插入到光标处，还有两条完整规则示例。
- **工具栏 Columnizer 下拉框：** 切换当前标签页的 columnizer；"Automatic (...)" 项显示当前自动选中的是哪个。
- **工具栏图标：** 图标由代码生成（`core/iconset.py` 里的矢量定义，`ui/icons.py` 渲染成当前主题文字颜色），没有图片文件。
 Options > Toolbar 可选：仅图标 / 仅文字 / 图标加文字（旁边或下方），以及图标大小；设置会保存。分离窗口的工具栏同步生效。
- **Ctrl+F 带入选中文本：** 在双击打开的字段编辑框里选中文字（双击默认全选）后按 Ctrl+F，文字自动填入查找框。
 勾选 Regex 时会自动转义，特殊字符按字面查找。多行选择取第一个非空行。
- **行间距：** 每个面板（主面板、过滤结果、搜索结果、书签）可单独设置 0 到 40 像素的额外行间距（Options > Appearance 的 Row spacing 列；
 默认值与以前的行高相同）。View > Row spacing 可以一次把所有面板加大或减小 1 像素，或恢复默认。自动换行模式下文字在行内垂直居中。
- **程序 Logo：** 放大镜加日志行。窗口、任务栏和 exe 使用同一份定义（`core/iconset.py` 的形状列表）。

### 打包成 Windows 可执行文件（无黑色控制台窗口）

```powershell
.\packaging\build_exe.ps1
# 等价于：
uv sync
uv run --with pyinstaller pyinstaller packaging/logscope.spec --noconfirm --clean
```

结果在 `dist\LogScope\LogScope.exe`（一个文件夹，整体复制即可）。`logscope.spec` 里 `console=False`，图标是 `packaging/logscope.ico`，
属性页的版本、作者来自 `packaging/version_info.txt`。改了 logo 或版本后运行
`uv run --with pillow python packaging/make_assets.py` 重新生成这几个文件。

**`uv sync` 生成的 `logscope-gui.exe` 弹出黑色窗口：**

1. `pyproject.toml` 里要有 `[project.gui-scripts]`，并指向 `logscope.app:gui_main`（本版已改）。改过入口后重新生成启动器：
  `uv sync --reinstall-package logscope`。
2. 双击的必须是 `.venv\Scripts\logscope-gui.exe`，不是 `logscope.exe`（`[project.scripts]` 生成的控制台版本，会带窗口）。
3. 即使用控制台版本启动，程序也会在没有 cmd / PowerShell 共用该窗口时自动关掉它（`winconsole.py`）。
  从终端启动不会被关；需要保留窗口时加 `--console`。
4. 没有控制台后看不到报错：未处理的异常会弹出对话框，并写入设置目录里的 `crash.log`；启动时的规则 / 插件问题写入 `startup.log`
  （默认 `%APPDATA%\LogScope`，`--portable` 时在程序旁边的 `LogScopeData`）。

**解析规则（Parsing rules）= 命名的正则 columnizer + 文件名模式**

- 菜单 View > Columnizer > Parsing rules…。每条规则有名字、正则（每个捕获组一列，命名组即列名）、可选的列标题、
 “不匹配的行”处理方式，以及 **Applies to files**：用 `;` 分隔的文件名模式。
- 文件名模式（不区分大小写，`\` 和 `/` 等价）：
 - `*.log`、`app_??.txt`：通配符，只比较文件名；
 - `logs/*.log`：带目录部分，和完整路径的结尾比较；
 - `re:/sys_\d+\.log$`：以 `re:` 开头是正则，在完整路径里搜索。
- 打开文件时，规则列表**从上到下**检查，第一条文件名模式匹配的规则直接生效，优先于内容自动检测；
 都不匹配则走原来的自动检测。手动选择的 columnizer 仍然优先，并保存在会话里。
- 规则列表支持上移 / 下移、复制、删除，以及导入 / 导出 JSON；全部保存在设置里（`regex_columnizers`）。
- 预览区显示当前文件前几行的解析结果，并提示当前文件是否匹配这条规则的文件模式。
- 派生标签页（过滤结果、合并）不按文件名匹配。

对话框里附带两个示例：

```
管道分隔：2026-11-13T17:02:13.447 | Info | Debug | 35308 | File.cpp:120 # 文本
^(?P<Timestamp>\S+)\s*\|\s*(?P<Level>\S+)\s*\|\s*(?P<Type>[^|]*?)\s*\|\s*(?P<Thread>[^|]*?)\s*\|\s*(?P<Source>[^#|]*?)\s*#\s?(?P<Message>.*)$

方括号时间戳：[2026-11-13T17:02:11.976]sys=I2C|;|room=...
^\[(?P<Timestamp>[^\]]+)\](?P<Message>.*)$
```

**Help > About**：版本、作者、版权、近期变更，以及 Python / PySide6 / Qt / NumPy 版本、平台和设置目录（可一键复制，用于报 bug）。
作者信息在 `src/logscope/about.py` 顶部的常量里修改。命令行 `logscope --version` 也会输出版本。

**每个面板内 Ctrl+F / F3 / Shift+F3，循环查找**
* 主视图、过滤结果面板、搜索结果面板、书签面板各有自己的查找栏：**光标在哪个面板里，Ctrl+F 就搜哪个面板**，F3 / Shift+F3 跳到下一个 / 上一个，搜到末尾（开头）自动绕回，并提示 “(wrapped around)”。Esc 关闭查找栏。
* 主视图搜的是整个文件（含 Regex / Case、Find all）；过滤 / 搜索结果面板在后台线程里只搜该面板的行；书签面板搜行号、标签、注释、文本所有列。
* 光标不在任何面板里（例如在过滤输入框）时，快捷键作用于当前标签页的主视图。

**多文件时间戳同步**
* 先把文件「关联」：Tab → Link files…（Ctrl+Shift+L，工具栏 Link files…）勾选要关联的文件；或 Tab → Linked（Ctrl+L）/ 标签页右键只切换当前文件。只有能解析出时间戳的文件才能关联（否则提示去设置时间戳格式）。关联的标签页标题前有 🔗，关联状态写入会话。
* 工具栏 **Sync time**（View 菜单 / Ctrl+Shift+Y）开关同步：打开时，在任一关联文件里**滚动或跳转**（双击结果、书签、Find、Go to line、F2 ……）到某行，其他关联文件自动选中并居中显示**时间戳最接近的那一行**。关闭后各自独立。该开关保存在 settings 的 `time_sync`。
* 只对有时间戳的文件生效；没有时间戳的行借用相邻带时间戳行的时间；日期完整的文件和「仅时间」格式的文件不会互相同步。被同步的标签页若正有多行选中（用于 Δt），只滚动、不改选区；被同步的文件会关闭 Follow tail。
* 每个文件可设 **Clock offset**（Tab → Clock offset…，或关联对话框里直接改），例如 `+01:00`、`-00:00:02.5`、`-250ms`、`3600`：用于不同机器 / 时区的时钟偏差，同步与合并都会加上它。
* 实现：二分查找，只解析几十行，500 MB 文件上瞬间完成；时间戳乱序时结果是近似的。

**关联文件合并显示（新 tab）**
* Analyze → Merge linked files → new tab（Ctrl+Shift+M，工具栏 Merge）：把所有关联文件的行按时间**穿插**成一个新标签页，时间按**毫秒**取整比较。
* 同一毫秒的行：每个文件的行聚成一个 block；上一行来自哪个文件，就让那个文件先继续，这样 block 被拆开的机会最小；没有上一行时按关联顺序。同一文件内部的原始顺序永远保持。
* 没有时间戳的行（堆栈等续行）归属上一条有时间戳的行，跟着它走；文件开头的无时间戳行归属第一条时间戳。时间戳倒退的行按「历史最大值」处理，保证单个文件内顺序不变。
* 每行前面多一列 **Source**，显示该行所在文件的完整路径；整行按**该文件标签页的颜色**着色（背景是标签颜色淡化后铺在面板底色上，文字颜色自动选黑 / 白保证可读；Source 列用标签颜色实色）。关联但还没有颜色的标签页，合并时自动分配一个颜色。高亮规则命中的行仍以高亮规则的颜色为准。修改源标签页的颜色，合并页立即跟着变。
* 合并页是普通的临时文件标签页：可过滤 / 搜索 / 书签 / Δt / Save tab as…；Ctrl+Shift+J 跳回原文件（若已关闭则重新打开）对应行；状态栏显示当前行来自哪个文件第几行。Columnizer 选择照常（Source 列会加在前面）。
* 后台线程合并，状态栏显示进度（读取时间戳 → 排序 → 写入）；约 40 字节 / 行内存；在本环境的慢速机器上 2×100 万行约 22 秒（主要是解析时间戳）。

**正则 Columnizer（每个捕获组一列）**
* View → Columnizer → Regex columnizers…：新建 / 复制 / 删除多个正则 columnizer，保存在 settings 的 `regex_columnizers`，启动时自动加载，列在 Columnizer 菜单里。
* 命名组 `(?<time>…)`（.NET 写法）或 `(?P<time>…)` 作为列标题，未命名的叫 Col 1、Col 2…；也可另填「Column titles」覆盖。最多 64 列。
* 选项：忽略大小写；整行任意位置匹配（默认从行首）；**不匹配的行**放进最后一列 / 第一列 / 不显示（默认最后一列，适合堆栈续行）；是否参与自动识别（默认关；开启后前 200 行中 ≥ 50 % 匹配就自动选用，同分时优先于内置的）。
* 对话框里有示例（日期时间等级、Apache 访问日志、key=value、CSV）和当前文件前 40 行的实时预览，正则写错时显示原因。
* 保存后已打开的标签页立即应用新的定义；在用的 columnizer 被删除则回到自动识别。

**时间戳解析与时间差**
* 自动识别时间戳格式（取前 200 行，匹配率 ≥ 30 % 才采用（ 起；堆栈多的日志也能识别））：ISO 8601（`2026-11-10 12:34:56.789`、`T`、`Z`、`+01:00`）、`2026/11/10`、`10.11.2026`（日在前）、Apache（`10/Nov/2026:12:34:56 +0100`）、syslog（`Nov 10 12:34:56`，年份取当年）、epoch 秒 / 毫秒、仅时间 `12:34:56.789`。
* Analyze → Timestamp format…：自动 / 内置格式 / 自定义 strptime 格式（如 `%d.%m.%Y %H:%M:%S,%f`，支持 `%Y %y %m %d %H %M %S %f %b %B %z %p %I %j`），带实时预览；可设为新标签页的默认值。每个标签页单独记住，写入会话。
* 新 Columnizer「Timestamp | Message」：把时间戳拆成独立一列（Apache、syslog、epoch 等格式会被自动选中；ISO 日志仍默认用原来的 Timestamp / Level / Message）。
* **选中多行 → 状态栏实时显示时间差**：最后一行 − 第一行（按行号顺序）、有时间戳的行数、最大间隔（及其所在行）、平均间隔。主表、过滤结果、搜索结果、书签面板都支持。
* Analyze → Time difference of selected lines…（Ctrl+D）：详细报告，可复制。选中超过 20 万行时抽样（首尾 1000 行始终保留，所以「首尾差」仍然精确，最大 / 平均间隔为近似值）。
* 时间戳带时区时按 UTC 比较；不带时区的按原样比较。只有时间没有日期的格式不处理跨午夜（会得到负值）。

**过滤结果 / 书签 / 选中行 → 新主文件标签页（参照 LogScope 的 pipe 标签页）**
* 过滤面板 “To tab”、搜索结果面板 “To tab”、书签面板 “To tab”（有选中就用选中的，否则用当前列表）、Analyze 菜单（含 Ctrl+Shift+B 书签、Ctrl+Shift+T 选中行）。
* 实现方式：把这些行写入一个临时 UTF-8 文件，再当作普通文件打开——所以**二次过滤、搜索、书签、高亮、Columnizer、时间差全部可用**，可以层层嵌套。
* 书签转标签页时，注释、标签、emoji 标记一起带过去。
* 标签页状态栏显示来源和当前行对应的源行号；Ctrl+Shift+J（Tab 菜单 / 标签页右键）跳回源标签页的对应行（源标签页已关闭时重新打开源文件）。
* File → Save tab as…（Ctrl+S，工具栏 Save、标签页右键 Save as…）：另存为文件（原子写入）。普通文件标签页也能另存副本。
* 临时文件在关闭该标签页或退出程序时删除；已另存的副本不受影响。派生标签页不写入会话。
* 派生文件是「快照」：源文件继续增长不会同步到派生标签页。

**多文件、标签页颜色**
* File → Open 可多选，拖放多个文件、命令行传多个文件，每个文件一个标签页（此前已支持，对话框标题现在明确说明）。
* 标签页右键 / Tab 菜单：重命名（F6）、颜色（9 种预设 + 自定义 + 无）、复制完整路径、在资源管理器中显示、关闭其他。
* 颜色画在标签页顶部色条和淡色底上；按文件路径记住（settings 的 `tab_colors`，最多 300 条），也写入会话。

**多标签页布局 / 独立窗口**
* View → Layout（工具栏 Layout 按钮）：Tabs（一次一页）/ Side by side（并排）/ Stacked（上下堆叠）/ Grid（网格）。并排模式下所有标签页同时可见，每页有带颜色的标题栏（↗ 脱离、✕ 关闭），点击任意页即成为当前页（粗体标题 + 加粗边框）；各页之间可用分隔条调整大小。布局保存在 settings 的 `layout`。
* Tab → Detach（Ctrl+Shift+D，标签页右键、并排模式标题栏 ↗）：把标签页拿出来放进独立窗口，窗口有自己的菜单、工具栏、书签面板、状态栏和颜色条，菜单与快捷键与主窗口共用（作用于当前活动窗口的标签页）。关闭该窗口或再按 Ctrl+Shift+D = 放回主窗口；Ctrl+W = 真正关闭标签页。
* 独立窗口里的标签页会写入会话，下次启动时回到主窗口（窗口位置不保存）。

触发器的细节：

* 只对**应用过滤器之后新写入的行**生效，已有内容不会触发；文件还在建立索引时应用的过滤器，等索引完成后再开始监视。最后一行未写完（没有换行）时先不判断，等写完整再判断。
* “第一次匹配”= 触发一次后停止，直到再次点 Apply；“每次匹配”= 每个新匹配行启动一次，但每批新行最多启动 25 个（settings.json 的 `trigger_burst_limit`），超出的会在状态栏提示，防止日志刷屏时把机器拖垮。
* 命令写法：`C:\tools\notify.exe`、`"C:\Program Files\x\y.exe" --flag`、`python alert.py`、`alert.py`（用运行 LogScope 的 Python 执行）。程序在后台启动，不弹控制台窗口，不等待结束，输出丢弃。
* 安全：`.bat` / `.cmd` 会由 cmd.exe 解释参数，所以传给它们的参数里的 `& | < > ^ % " !` 会被替换成空格，需要原文请读环境变量 LOGSCOPE_LINE。会话文件 / 过滤器文件里带动作时，加载前会列出命令并询问是否保留。
* 目前每个标签页同一时间只监视“当前这个过滤器”的动作。

其他说明：高亮词绘制时超出列宽的部分直接裁剪（不显示省略号）；彩色 emoji 能否显示取决于 Qt 和 Windows 字体回退（Segoe UI Emoji），不显示时请换成普通符号。

### 文件格式
* 书签文件 `*.bookmarks.json`：`{"version":1,"file":"...","bookmarks":[{"line":42,"comment":"...","text":"..."}]}`，`line` 为 1 起始的行号。
* 会话文件：`{"version":1,"tabs":[{path, bookmarks, follow, line, columnizer, filter, filter_visible}],"current":0}`。
* 高亮导出文件：`{"version":1,"groups":{"组名":[{pattern, regex, case_sensitive, fg, bg}]}}`；导入时也接受单组格式 `{"name":..,"rules":[..]}`。
* 设置文件位置：`%APPDATA%\LogScope\settings.json`（便携模式：`LogScopeData\settings.json`）。
